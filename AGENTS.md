# Capacity Planner portfolio edition

This is a personal portfolio edition of an earlier capacity-planning exercise.
Read README.md, docs/API.md and docs/ARCHITECTURE.md. Preserve the supplied synthetic schema/seed and the historical DECISIONS.md; they explain the original scope.

Keep private planning outside the repository. No assessment submission workflow is active here.
